Taxi Time v1.0
Standard taxi time per airport, managed by fleet group and effective period. Region rows are added/removed as needed, airport codes use ICAO. Each period shows Active / Scheduled / Expired against today's date; Active or Scheduled periods can be deleted (Expired cannot), and the previous period absorbs the deleted one's end date so the chain never gains a gap. A fleet group's first period may be scheduled ahead but never backdated, and the save dialog spells out exactly which record each date belongs to.

System Log v0.1
Single place that collects the action history of the whole system — both what users do (add, edit, delete) and what the system does on its own (scheduled jobs, data source synchronisation). Filter by subsystem, date range, user, module and action; every entry shows who changed what, from which device, and the before/after values.
