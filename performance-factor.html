The specific-range deviation column has two names: PEP calls it DSR, PET calls it FM Dev. Same quantity, same unit, same formula.
Outlier rule (M2-6): two stages, applied per aircraft within the selected range. Stage 1 removes values beyond the absolute threshold ±15%; stage 2 removes values outside ±2σ around the mean of what remains. Excluded records are still stored, flagged Outlier, and left out of the average. Stage 2 is skipped when fewer than 3 readings remain.
Duplicate records ARE counted in the average; the Duplicate flag is for visibility only.
Green marks an aircraft performing better than the manufacturer baseline: DSR positive or PF negative. The two always carry opposite signs, so cells in the same row share one colour.
PF FMC is empty for the Boeing fleet because the PET output has no FLHV field to compute the FLHV correction (the configuration block only states Fuel LHV Adjustment = Yes). Pending customer clarification.

PF FMC (calc) is the raw formula result. PF FMC (applied) has the "positive values forced to 0" rule applied, and is the value used for reporting and release. The calculated value is retained so no data is lost if that rule changes later.
